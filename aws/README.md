# AWS

This folder contains AWS cloud security labs focused on identity and access management, CloudTrail analysis, compromised credentials, malicious resource deployment, S3 security, and cloud incident investigation.

## Topics Covered

- AWS Identity and Access Management (IAM)
- AWS CloudTrail log analysis
- Compromised credential investigation
- IAM reconnaissance and persistence attempts
- CloudFormation activity
- EC2 resource deployment
- Security group analysis
- S3 bucket security
- S3 versioning changes
- S3 object access, deletion, and exfiltration
- Cloud incident timeline reconstruction
- Least-privilege analysis
- Security control analysis
- Remediation recommendations
